# 통합과학 방탈출: 138억 년의 여정

고등학교 1학년 **통합과학1 · 1학기 복습용** 웹 방탈출 게임입니다.
타임머신 오류로 약 138억 년 전 초기 우주에 떨어진 학생들이, 우주의 역사 순서대로
네 개의 방을 통과하며 **시간 좌표 칩** 4개를 모아 현재로 귀환하는 2D 포인트 앤 클릭 방탈출입니다.

- **대상**: 통합과학1을 한 학기 학습한 고1 학생
- **권장 인원**: 2~3명 (한 팀이 한 화면으로 플레이)
- **예상 시간**: 약 35~40분

## 실행 방법

별도의 서버·데이터베이스·API 키·빌드 과정이 **필요 없습니다.**

1. **가장 간단한 방법** — `index.html` 파일을 브라우저(크롬 권장)로 더블클릭해 엽니다.
2. **로컬 서버로 실행(선택)** —

   ```bash
   # 프로젝트 폴더에서
   python3 -m http.server 8000
   # 브라우저에서 http://localhost:8000 접속
   ```

## 파일 구조

```
index.html      # 진입점: 시작 화면·프롤로그·게임·결과 화면의 뼈대, 공통 모달
styles.css      # 공통 디자인, 방별 테마, 퍼즐/자물쇠 UI, 반응형, 접근성, 애니메이션
js/data.js      # 정적 데이터: SVG 아이콘, 아이템 정의, 정답(ANSWERS), 3단계 힌트, 오답 피드백, 프롤로그
js/engine.js    # 게임 상태, localStorage 저장/복구, 사운드(Web Audio), 모달·토스트, 퍼즐 공통 빌더
js/puzzles.js   # 방 1~4의 오브젝트 조사 및 16개 퍼즐 + 4개의 최종 잠금장치 구현
js/main.js      # 방 데이터(오브젝트 배치), 화면 전환, 프롤로그, 타임머신(최종 탈출), 결과, 초기화
README.md       # 이 문서
```

> `script.js` 하나 대신 역할별로 4개의 파일로 분리했습니다. 모두 일반 `<script>` 태그로
> 로드되며 번들러/빌드 도구 없이 브라우저에서 바로 실행됩니다.

## 게임 범위 (교육과정)

정확히 아래 네 소단원만 다룹니다. 각 소단원이 하나의 방입니다.

| 방 | 소단원 | 최종 잠금장치 |
|---|---|---|
| 방 1 · 초기 우주 연구소 | 우주 초기에 생성된 원소 | 5자리 숫자 패드락 (`33138`) |
| 방 2 · 별의 원소 생성실 | 별의 진화와 원소의 생성 | 복합 자물쇠 (다이얼 4 · 탄소 · 철 · 철보다 무거운 원소) |
| 방 3 · 지구시스템 관제실 | 지구시스템의 구성과 상호작용 | 4칸 아이콘 회전 자물쇠 (구름→잎→암석→구름) |
| 방 4 · 판 구조 제어실 | 지권의 변화와 판 구조론 | 3단 슬라이더 자물쇠 (발산형→보존형→수렴형) |

최종 탈출: 칩을 우주의 역사 순서로 배열 → 최종 시간 좌표 **38443** 입력.

H-R도, 별의 최종 운명 분류(백색 왜성·중성자별·블랙홀), 외권(5번째 권역), 암석 순환 등
범위 밖 내용은 포함하지 않으며, 원소 생성을 He→C→Fe→Au식 일렬 순서로 제시하지 않습니다.

## 주요 기능

- **방 탐색** — 방마다 6~8개의 클릭 가능한 오브젝트(서랍·벽보·관측 장치·기록지·모형), 잠금/완료 상태 표시
- **퍼즐 연쇄** — 퍼즐을 풀면 다음 장치에 전원이 들어오거나 잠긴 서랍이 열리는 구조 (건너뛰기 불가)
- **다양한 조작** — 카드 순서 배열, 분류/매칭, 드래그 앤 드롭(+클릭 선택 대체 조작), 입자 조립,
  숫자 패드락, 아이콘 회전식 자물쇠, 슬라이더 자물쇠, 복합 자물쇠, 지도에서 판 경계 찾기
- **인벤토리** — 사건 카드·필름·문양·권역 아이콘·좌표 칩 등을 획득/사용 상태로 관리, 클릭 시 상세 설명
- **3단계 힌트** — 퍼즐마다 개념 힌트 → 조작 안내 → 정답 일부 공개. 사용 횟수는 결과 화면에 기록
- **오답 피드백** — “틀렸습니다”가 아니라 관련 개념을 되짚는 문장 제시, 즉시 재시도 가능
- **자동 저장** — 퍼즐 해결·아이템 획득·힌트·방 이동 시 localStorage에 저장, 새로고침 후 「이어하기」
- **연출** — 프롤로그(건너뛰기 가능), 핵융합 섬광, 초신성 폭발, 물 순환 애니메이션, 시간 터널 귀환
- **접근성** — 키보드 조작(Tab/Enter/ESC), 포커스 스타일과 복귀, aria-label, `prefers-reduced-motion` 지원,
  색+아이콘+텍스트 병행 표시, Web Audio 효과음(기본 꺼짐)
- **반응형** — PC(1920×1080, 1366×768) 우선, 태블릿/모바일에서는 오브젝트가 목록형 그리드로 전환

## 배포 방법

정적 파일뿐이므로 아무 정적 호스팅에나 올리면 됩니다.

- **GitHub Pages**: 저장소 Settings → Pages → 브랜치 선택(root) → 발급된 주소로 접속
- **학교 서버/클라우드**: 폴더 전체를 업로드
- **오프라인 수업**: 폴더를 USB로 배포해 `index.html` 실행 (인터넷 불필요)

## 교사용 참고 (스포일러)

- 방 1 패드락 `33138` = 우주 시계(3) → 질량 저울(3:1) → 우주 달력(38)
- 최종 좌표 `38443` = 38(원자 형성, 38만 년) · 4(수소 원자핵 4개) · 4(네 권역) · 3(판 경계 3유형)
- 진행 초기화: 상단 바 「↻ 처음부터」 버튼, 또는 브라우저 개발자 도구에서
  `localStorage.removeItem('is1escape_save_v1')`
