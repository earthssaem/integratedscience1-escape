# ARKHE — 138억 년의 귀환 · 3D

통합과학 1학기 복습용 **3D 방탈출 게임**입니다.
학생은 탐사선 아르케(ARKHE) 호의 승무원이 되어, 빅뱅 직후(138억 년 전)부터 현재까지
다섯 시대의 방을 차례로 탈출하며 통합과학 개념을 복습합니다.

Vite + React + three.js 로 만들어졌습니다.

## 게임 구성

| 방 | 시대 | 미션 (통합과학 개념) |
|---|---|---|
| ROOM 01 — 불투명한 우주 | 빅뱅 직후 | 입자 생성 순서 · 우주 배경 복사 · 흡수 스펙트럼 |
| ROOM 02 — 별의 용광로 | 항성 내부 | 수소 핵융합(헬륨 조립) · 점화 온도 · 초신성 |
| ROOM 03 — 원시 지구 | 46억 년 전 | 별의 진화(블랙홀) · 지구 형성 과정 |
| ROOM 04 — 살아있는 시스템 | 현재 · 지구 궤도 | 지구시스템 상호작용 · 물 순환 평형 |
| ROOM 05 — 귀환 좌표 | 착륙 시퀀스 | 변동대(지진대·화산대) · 판 경계 유형 |

- **오답 +30초 / 힌트 +10초** 페널티, 방마다 숨겨진 **✦ 크로노 크리스털(-20초)**
- WASD·방향키·터치 패드로 이동, 드래그로 시점 회전, 빛나는 장치를 탭하여 퍼즐 진행

## 기록 제출 방식 (데이터베이스 없음)

이 버전은 서버·데이터베이스에 연결하지 않습니다.

1. 시작 화면에서 **닉네임만** 입력하고 게임을 시작합니다.
2. 모든 방을 탈출하면 엔딩 화면에서 **「결과 보고서 저장」** 버튼으로
   결과 이미지(PNG)를 저장할 수 있습니다.
3. 학생은 저장한 보고서 이미지를 **선생님께 제출**합니다.
   - 보고서에는 닉네임 · 최종 기록 · 오답/힌트 횟수 · 크리스털 개수 · 완료 시각과 함께
     간단한 **제출 코드**(기록 위변조 확인용 해시)가 표시됩니다.

## 실행 방법

```bash
npm install
npm run dev      # 개발 서버 (http://localhost:5173)
npm run build    # 배포용 빌드 → dist/
npm run preview  # 빌드 결과 미리보기
```

`vite.config.js` 에 `base: "./"` 가 설정되어 있어 GitHub Pages 등
하위 경로에도 그대로 배포할 수 있습니다 (`dist/` 폴더를 업로드).

## 교사용 설정

- 대사 속 교사 이름: `src/App.jsx` 상단의 `TEACHER_NAME` 수정
- 제출 코드 검증: 같은 닉네임·기록이면 항상 같은 코드가 나오므로,
  의심스러운 보고서는 값을 `submitCode` 함수(`src/App.jsx`)에 넣어 대조할 수 있습니다.
